# 全牌组高级特效设计

## 目标

为全部 78 张塔罗牌提供可见且有区分度的揭牌特效，并将当前依赖明显圆点粒子的视觉重制为连续、克制、具有空间层次的 GPU 效果。四花色继续表达火、水、风、土；22 张大阿卡那按六种视觉原型分组。Anime.js 负责编排生命周期和 shader 参数，Three.js 负责渲染。

不改变抽牌随机性、正逆位结果、手势识别、牌阵位置或 AI 解读输入。

## 已确认问题

当前 profile 只接受 `type === "minor"`，所以 22 张大阿卡那必然返回空效果。56 张小阿卡那映射完整，四花色各 14 张。控制器只保存一个活动实例，准备下一张牌时会销毁上一张牌的稳定效果，进一步造成覆盖不完整的感受。

## 视觉原则

- 粒子只作为辅层，不能成为主体；标准档也使用稀疏、小尺寸、低透明度微粒。
- 主体由 shader 光幕、连续光带、焦散、噪声形变、等高线和法阵构成。
- 不使用大面积纯色遮挡牌面，不使用高频闪白，不制造廉价烟花感。
- 每种效果具有预热、揭牌爆发、稳定阅读三种清晰状态。
- 参考 React Bits 的 Liquid Ether、Silk、Light Rays、Topography、Aurora 和 Plasma 的视觉方法，但以原生 Three.js 重写，不引入 React 运行时。

## 小阿卡那四元素

### 权杖 / 火

主体为沿牌边上升的熔融光丝和低频热浪形变，揭牌时由底部向上点燃。火星只保留少量针尖状高光，逆位改为向内回卷和下沉，不改变色相。

### 圣杯 / 水

主体为流体噪声光幕、薄层焦散和椭圆涟漪。揭牌时涟漪由牌心扩散，稳定后形成低速环流；逆位向内收束并产生局部反向流动。

### 宝剑 / 风

主体为半透明丝带、方向性光束和短促切光。揭牌时两至三道风刃错峰掠过牌外缘，稳定后只保留柔和气流；逆位反向旋转并增加轻微紊流。

### 星币 / 土

主体为金色等高线、几何法阵和低频材质脉冲。揭牌时线条逐段成形，稳定后留下克制的拓扑呼吸；逆位使法阵断续并让少量尘埃上浮。

## 架构

### Effect profile registry

用统一 `createCardEffectProfile(card, orientation, tier)` 替换仅支持小牌的入口：

- 小牌根据花色生成四元素 profile；
- 大牌根据卡牌 id/name 查找六原型定义；
- 未知或畸形牌数据显式报错，不静默吞掉；
- profile 包含 `family`、`variant`、色板、方向、强度、速度、粒子预算和几何参数。

### Renderer

渲染器由三个批次层组成：

1. `field`：ShaderMaterial 平面或带状几何，承载连续噪声、流体或光幕；
2. `glyph`：线段、环和符号几何，承载描边与结构；
3. `accents`：稀疏微粒或短线，只做高光点缀。

各原型通过材质策略和几何构造器组合，不复制完整生命周期代码。所有几何、材质和动画句柄由实例拥有并在销毁时释放。

### Anime.js orchestration

Anime.js 只驱动可序列化的 envelope/uniform 状态，不拥有应用状态：

- `prepare`：低强度淡入和轻微形变；
- `reveal`：约 700–1100ms 的错峰光强、展开、扭曲和符号描边；
- `settle`：约 900–1400ms 回落到低强度循环；
- `dispose`：取消当前动画，迟到回调不得访问资源。

### Multi-instance controller

控制器以牌或牌位为 key 管理实例。最多保留三个已落位效果和一个手持预热效果：

- 取消手持牌只清理手持实例；
- 新抽牌不会销毁已落位实例；
- 牌阵结束后三个实例保持低强度稳定状态；
- 新一局、页面卸载或上下文丢失时统一释放。

## 性能与无障碍

- `standard`：完整 field + glyph + 稀疏 accents；
- `low`：降低 shader 分辨率/几何段数，关闭次级光带，进一步减少 accents；
- `reduced`：禁用持续流动和爆发，只显示一次短淡入的静态色光与简化符号；
- 每帧只更新活动且可见的实例，delta time 上限为 100ms；
- 保持现有 WebGL 单 renderer，不引入额外 canvas 和 React/OGL 运行时。

## 错误处理

- profile 或高级材质创建失败时降级到简化光环，不阻断抽牌；
- Anime.js 不可用时直接应用各阶段最终值；
- 大牌映射缺失在测试和开发阶段立即失败；
- dispose 保持幂等。

## 验证

- 数据集 78 张牌全部生成 profile：56 张小牌、22 张大牌；
- 四花色及六原型映射数量正确；
- 每个视觉家族创建预期的 field/glyph/accents 层；
- Anime.js 驱动真实材质或 uniform 状态；
- 三个牌位效果可同时稳定存在，新抽牌不清理旧牌；
- 取消、重开和销毁释放全部资源并取消动画；
- reduced motion 不运行持续动画；
- 完整单元测试、烟雾测试和构建检查通过，并在浏览器中人工检查桌面与窄屏视觉。
